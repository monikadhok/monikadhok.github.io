Now

Building software for people who don't write code

I'm a software engineer at Google on the Workspace team. I worked on bringing Gemini to Apps Script, which is now generally available. You open Extensions › Apps Script in Sheets, Docs, Slides or Forms, describe a repetitive task in everyday language, and Gemini writes the script.

The interesting problems come after the code is generated: reviewing a change block by block, fixing errors in one click, and making sure the automation behaves the way the person intended.

Research

Program analysis, from the lab to products used by billions

My PhD at the Indian Institute of Science (IISc) was in program analysis and software engineering. My work used dynamic analysis, which means studying programs while they run, for automated test generation and performance improvement.

I joined Google to take those ideas into products. Google later featured my move from PhD research to product engineering.

I think AI-generated code makes this field more important, not less. When nobody wrote the code by hand, tools that generate tests and explain behaviour become the way we trust it.
